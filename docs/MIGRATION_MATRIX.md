## 下一批建议顺序

1. **发布级测试**：MediaSession、进程回收、OpenDocumentTree、歌单/M3U、快捷入口和歌词导入仪器化测试。
2. **性能工程**：Baseline Profile、Macrobenchmark、10,000 首混合库、大型歌单和超大队列。
3. **M3U 与历史迁移**：导入预览、歧义手工映射、相对路径和 MediaStore Playlist 只读导入。
4. **规则智能列表**：时间窗口、播放完成度、时长、目录和标签组合。
5. **旧特色**：歌词编辑/双语、Glance 小组件、Live2D 隔离层和音频标签编辑。
