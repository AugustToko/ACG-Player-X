## 下一批建议顺序

1. **SAF 文件夹入口**：支持用户授权但 MediaStore 未索引的目录，并建立可恢复 URI 权限模型。
2. **发布级测试**：MediaSession 仪器化、进程回收、歌词导入、Baseline Profile 和 10,000 首压力数据。
3. **队列与歌词增强**：长按拖拽、批量队列操作、同目录歌词自动匹配、双语与歌词编辑。
4. **Glance 小组件**：在播放核心稳定后恢复旧版桌面控制能力。
5. **Live2D 隔离适配**：以独立 AndroidView 生命周期接入，不污染主导航与播放状态。
