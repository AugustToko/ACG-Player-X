## 下一批建议顺序

1. **歌词只读闭环**：LRC 解析、时间轴匹配、逐行高亮、偏移调整和无歌词状态。
2. **播放队列 UI**：查看、拖动排序、删除、跳转、清空和持久化一致性。
3. **SAF 文件夹入口**：支持用户授权但 MediaStore 未索引的目录。
4. **发布级测试**：MediaSession 仪器化测试、进程回收、Baseline Profile 和 10,000 首压力数据。
5. **Glance 小组件**：在播放核心稳定后恢复旧版桌面控制能力。
