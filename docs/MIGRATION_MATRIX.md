## 下一批建议顺序

1. **发布级测试**：MediaSession、进程回收、OpenDocumentTree、快捷入口、歌词导入和队列编辑仪器化测试。
2. **性能工程**：Baseline Profile、Macrobenchmark、10,000 首 MediaStore+SAF 混合库及超大队列压力数据。
3. **规则智能列表**：时间窗口、播放完成度、时长、目录和标签组合。
4. **队列与歌词增强**：长按拖拽、批量操作、同目录歌词自动匹配、双语与歌词编辑。
5. **Glance 小组件**：在播放核心稳定后恢复旧版桌面控制能力。
6. **Live2D 隔离适配**：以独立 AndroidView 生命周期接入，不污染主导航与播放状态。
