## 下一批建议顺序

1. **发布级测试**：MediaSession、进程回收、OpenDocumentTree、歌单/M3U、快捷入口、歌词导入和队列编辑仪器化测试。
2. **性能工程**：Baseline Profile、Macrobenchmark、10,000 首混合库、大型歌单及超大队列。
3. **歌单交互增强**：长按拖拽、批量选择、Snackbar 撤销、导入预览与手工映射。
4. **规则智能列表**：时间窗口、播放完成度、时长、目录和标签组合。
5. **歌词与旧特色**：同目录歌词、编辑/双语、Glance 小组件、Live2D 隔离适配。
